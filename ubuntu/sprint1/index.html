8. Instal·lació d'aplicacions

Pinning de paquets amb APT

Primer vaig comprovar la política d'APT del paquet curl amb la comanda sudo apt-cache policy curl. El paquet encara no estava instal·lat i la versió candidata era la 8.5.0-2ubuntu10.

Després vaig crear el fitxer de preferències amb la comanda sudo nano /etc/apt/preferences.d/curl-pin. A la primera regla vaig posar prioritat 400 per a tots els paquets i a la segona vaig fixar curl a la versió 8.5.0-2ubuntu10 amb prioritat 1000.

Finalment vaig provar d'instal·lar el paquet amb sudo apt install curl i va aparèixer un error de dependències. Aquest error és normal i demostra que el pinning funciona. El paquet curl fixat a la versió 8.5.0-2ubuntu10 necessita exactament la mateixa versió de la llibreria libcurl4t64. APT, però, intenta instal·lar la versió més nova (8.5.0-2ubuntu10.15) d'aquesta llibreria, i les dues versions no són compatibles. Per això APT no pot resoldre les dependències i mostra el missatge d'error.
